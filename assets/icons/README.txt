LP用アイコン 3点（SVG）

01_strength.svg：強みを言葉にする
02_connection.svg：仲間とつながる
03_next_step.svg：次の一歩を踏み出す

・すべて背景透過、単色のベクターパスです。
・viewBoxは3点とも0 0 512 512です。
・初期色は #F7C456。各SVGの fill="#F7C456" を希望の色に変更できます。
・Illustratorなどで開き、塗りの色を変更することもできます。
・SVGをHTMLへ直接記述する場合は、fill="currentColor"にしてCSSのcolorから色を指定できます。
・imgタグから読み込む場合は、SVG内のfillを変更してください。
